A lightweight, user-friendly tool designed to generate secure, randomized passwords instantly. With only python

This tool includes all the **ASCII characters** with the choice of characters length and amount genererated of yours.


### Prerequisites
Make sure you have [Python 3.x](https://python.org) installed on your machine.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/DaRealDSA/passgenerator_cli
   ```
2. Navigate to the project directory:
   ```bash
   cd passgenerator_cli
   ```

### Usage
Run the application directly from your terminal:
```bash
python main.py
```
### Core Libraries that are being used
1. random
2. string
3. colorama
